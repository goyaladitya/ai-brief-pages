# Data Directory

This directory contains pre-generated JSON data files for the static frontend.

## Files

- `latest.json` - The most recent brief
- `briefs.json` - Index of all available briefs
- `briefs/` - Archived briefs by date (YYYY-MM-DD.json)

## Generation

These files are automatically generated by GitHub Actions using:

```bash
ai-brief export --output-dir frontend/data
```

Briefs are updated daily at 3 AM UTC.
